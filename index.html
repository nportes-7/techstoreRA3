Bem-vindo à TechStore

A TechStore é uma loja virtual de eletrônicos desenvolvida como projeto final da disciplina RA 3.

Nosso catálogo utiliza a API DummyJSON para apresentar produtos de tecnologia de forma dinâmica, utilizando requisições HTTP e manipulação de dados com JavaScript.

Conheça produtos de fabricantes como Apple, Samsung, Xiaomi e Huawei.
